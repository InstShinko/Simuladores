# Simulador Académico

Plataforma de simulación para prácticas educativas con múltiples materias y trimestres.

## Materias disponibles
- Ciencias Sociales I (completo: 9 actividades, 90 preguntas)
- Quinto trimestre: seis materias académicas, 90 preguntas por materia.
- Sexto trimestre: Organismos y evolución biológica, Conciencia histórica III, Temas selectos de matemáticas II, Cálculo integral, Administración II, Ciencias de la salud II y Derecho II; 30 preguntas por materia.
- Recursos socioemocionales V y VI se omiten porque se trabajan mediante actividades personales.

## Tecnologías
- HTML5, CSS3, JavaScript
- Firebase Authentication
- Firebase Hosting (opcional)

## Cómo usar
1. Inicia sesión con tu cuenta (creada por el administrador)
2. Selecciona trimestre, materia y actividad
3. ¡Comienza a practicar!
